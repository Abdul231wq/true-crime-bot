# True Crime Bot

Плоская HTML-версия. Залейте эти файлы в корень репозитория GitHub.

- GitHub Pages: Settings → Pages → Deploy from branch → `/ (root)`
- Открывается `index.html`

Файлы: `index.html` `case.html` `board.html` `control.html` `style.css` `data.js` `game.js` `ai_engine.js` `app.js`

Три дела: D-0147 Закрытая комната → D-0203 Ночная аптека → D-0311 Пожар на складе.

Очки тратятся на обыск, допрос, очную ставку, гипотезу и подсказки. Жизнь снимается только за неверный вердикт. Верный вердикт сразу открывает следующее дело. Доска — пробковая стена: снимки, записки и красная нить; текст улики открывается в боковой карточке.
